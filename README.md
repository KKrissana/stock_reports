Stock Reports

## Features

- Generate comprehensive stock reports
- Filter reports by date, product, picking, and more
- Export reports to PDF and Excel
- User-friendly interface integrated with Odoo Inventory

## Requirements

- Odoo 18.0 (Enterprise or Community)
- Python 3.8+
- Required Odoo dependencies (see your Odoo installation)

## Installation

1. **Clone or copy** this module into your Odoo addons directory:
    ```
    git clone KKrissana/stock_reports
    ```
    Or copy the `stock_reports` folder to your Odoo addons path.

2. **Update the Odoo addons path** in your `odoo.conf` file if necessary:
    ```
    addons_path = /path/to/your/odoo-addons,/path/to/your/other-addons
    ```

3. **Restart** your Odoo server:

4. **Activate Developer Mode** in Odoo.

5. **Go to Apps**, click "Update Apps List", then search for "Stock Reports" or "stock_reports".

6. **Install** the "Stock Reports" module.

## Usage

1. Navigate to **Inventory > Reporting > Reports > Audit Reports >**.
